# Otrio Web

## Otrio とは？
３目並べの派生版で自分のコマを並べるところまでは同じですが、それぞれのマスは３つのリングになっており勝利条件は少し異なります
1. 自分のコマを同じマスの上に、自分の大・中・小のコマを置く
2. 自分のコマを同じ大きさでタテ・ヨコ・ナナメに３つ並べる
3. 自分のコマを大きい順、もしくは小さい順にタテ・ヨコ・ナナメに３つ並べる

2人プレイの場合は各プレイヤーは2色の色を使います
3人プレイの場合は一つの色を除外しそれぞれで遊びます
4人プレイの場合は4つの色をそれぞれ選んで使えます

3つ並べられたら「オートリオ！」と宣言します。**言わないとたとえ揃っててもゲームは続行します**
